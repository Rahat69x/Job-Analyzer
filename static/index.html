5. Empirical Answers to Core Research Questions (Section 9)

Every statement below is strictly grounded in empirical analysis of 34,979 real job postings and 71,913 verified salary observations.

QUESTION 1

Which AI/data roles appear most frequently?

Data Engineer (31.02%), Data Analyst (28.41%), and Data Scientist (25.63%) comprise 85.06% of all job postings. Data infrastructure and analytics dominate the job market over pure modeling. Dedicated Machine Learning Engineers (2.42%) and AI Engineers (0.20%) represent specialized high-growth niches.

QUESTION 2

Which skills are most demanded?

SQL (50.46%) and Python (49.90%) are the undisputed core requirements for any AI/data professional, appearing in half of all requisitions. They are followed by cloud providers AWS (19.05%) and Azure (17.64%), and BI tools Tableau (15.95%) and Power BI (15.10%).

QUESTION 3

Which locations have the most opportunities?

The United States (23.13%) represents the largest single geographical market (8,092 postings), followed by India (8.55%), United Kingdom (6.53%), France (6.32%), and Germany (4.01%). Significant remote hubs also hire globally across Southeast Asia and South Asia / Bangladesh.

QUESTION 4

How does experience relate to salary?

Seniority demonstrates a steep, consistent multiplier on annual compensation:
• Entry Level: Median $90,188 (Mean $98,017)
• Mid Level: Median $136,250 (+51% over Entry)
• Senior: Median $167,800 (+86% over Entry)
• Lead / Executive: Median $202,000 (+124% over Entry)

QUESTION 5

Which skills commonly appear together?

Python + SQL is the single most prevalent co-occurring pair, appearing jointly in 11,601 job postings. Other common clusters include Python + AWS and Python + Spark (Data Engineering/Cloud), SQL + Tableau / Power BI (BI Analytics), and Python + PyTorch / TensorFlow (Deep Learning).

QUESTION 6

How common are remote roles?

11.79% of all postings are advertised as 100% Fully Remote, with Data Engineers enjoying the highest remote flexibility (14.44%) and Data Scientists at 11.74%. The remaining 88.21% remain On-site or Hybrid due to enterprise security and governance considerations.

Power BI Star Schema & DAX Measures

// Primary DAX Measures included in powerbi/DAX_Measures.dax
Total Jobs = COUNTROWS('Fact_JobPostings')

Remote Job % = 
DIVIDE(
    CALCULATE(COUNTROWS('Fact_JobPostings'), 'Fact_JobPostings'[work_model] = "Remote"),
    [Total Jobs],
    0
)

Avg Salary USD = AVERAGE('Fact_JobPostings'[salary_usd])

Skill Penetration % = 
DIVIDE(
    DISTINCTCOUNT('Fact_JobPostings'[job_id]),
    CALCULATE(DISTINCTCOUNT('Fact_JobPostings'[job_id]), ALL('Dim_Skills')),
    0
)

Production SQL Query Suite

-- Query 1: Top Demanded Job Titles (Market Share & Remote Ratio)
SELECT 
    standardized_title,
    COUNT(*) AS total_postings,
    ROUND(COUNT(*) * 100.0 / (SELECT COUNT(*) FROM ai_jobs), 2) AS market_share_pct,
    ROUND(SUM(CASE WHEN work_model = 'Remote' THEN 1 ELSE 0 END) * 100.0 / COUNT(*), 2) AS remote_pct
FROM ai_jobs
GROUP BY standardized_title
ORDER BY total_postings DESC;

-- Query 2: Top 15 Technical Skills Overall
SELECT 
    s.skill_name,
    COUNT(s.job_id) AS demand_frequency,
    ROUND(COUNT(s.job_id) * 100.0 / (SELECT COUNT(*) FROM ai_jobs), 2) AS penetration_pct
FROM job_skills s
GROUP BY s.skill_name
ORDER BY demand_frequency DESC
LIMIT 15;
